# The DOS font

`PxPlus_IBM_VGA_8x16.ttf` is the text font of the IBM VGA card (8 x 16 pixels, code page 437, with more of Unicode),
from **The Ultimate Oldschool PC Font Pack** v2.2 by **VileR**, <https://int10h.org/oldschool-pc-fonts/>.
